# Portfolio Changelog

All notable changes, structural evolutions, and engineering milestones of this portfolio repository are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.0] - 2026-10-10

### Added
- **Core Architecture:** Responsive single-page layout utilizing modern semantic HTML5 and vanilla CSS.
- **Visual Identity:** Signature Bianca dark theme featuring obsidian surfaces (`#0B0D0B`) and vibrant lime accents (`#8AFF65`).
- **Interactive Terminal:** Dynamic terminal emulator window highlighting real-time engineering role transitions via Typed.js.
- **Circular Badge:** Pure CSS keyframe continuous rotation badge (`BUILD · EXPERIMENT · LEARN · ENGINEER ·`).
- **Centralized Schema:** Decoupled data model in `portfolio-data.js` for single-point configuration of projects, links, and profile details.
- **Verified Project Demos:** Direct verified endpoints for SOMed-AI, EcoRevive, and Smart EV Charging Hub.
- **Recruiter Resources:** Direct downloadable LaTeX-compiled PDF resumes (`Naitik_Sharma_Resume.pdf`).
- **Technical Documentation:** Comprehensive architecture, design system, deployment guide, and performance specifications in `/docs`.
